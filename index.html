Introducción

DonaDrops es un plugin de Minecraft (Paper, Java 17+, apuntado a 1.20.4) creado por Donatier que convierte cualquier cofre en un "drop chest": un cofre con nombre y color propio, rareza en estrellas, categoría, holograma flotante, una lista de recompensas que se sortean al abrirlo y paneles decorativos no removibles alrededor del loot.

Comandos

Comando Descripción
/dd create <nombre> [rareza 1-5] [categoría]Crea un cofre a partir del cofre que estás mirando.
/dd spawn <nombre>Genera ese cofre en tu ubicación actual.
/dd editor <nombre>Abre el editor GUI de un cofre existente.
/dd topsAbre el menú de rankings.
/dd reloadRecarga config.yml, categories.yml, idiomas y drops.
/dd authorMuestra la información del plugin y el autor.
/dd helpLista todos los comandos.
/dd locate <nombre>Lista todas las ubicaciones donde ese cofre está actualmente generado en el mundo.
/dd give <jugador> <nombre>Da directamente al jugador el contenido de ese cofre, sin generar el bloque.
/dd copy <origen> <nombre-nuevo>Duplica un cofre existente (rareza, categoría, recompensas, comandos, tipo de bloque...) bajo un nombre nuevo.
/dd respawnallRefresca el holograma de todos los cofres actualmente generados.
/dd delete <nombre>Elimina el drop registrado y retira sus apariciones activas.
/dd zonewandEntrega el hacha de hierro de DonaDrops para seleccionar Pos1 y Pos2.
/dd pos1 <x> <y> <z> [mundo]Define la primera posición de una zona.
/dd pos2 <x> <y> <z> [mundo]Define la segunda posición de una zona.
/dd createzone <nombre>Crea una zona con la selección actual y muestra una confirmación clicable antes de guardarla.
/dd deletezone <nombre>Elimina una zona y sus límites dejan de restringir el spawn.
/dd createspawn <nombreSpawn> <nombreCofre>Crea un punto fijo de aparición para ese cofre en tu ubicación actual (ver Puntos de spawn fijos).
/dd deletespawn <archivo>Elimina un punto de spawn fijo (el nombre de archivo es <cofre>_<nombreSpawn>).
/dd listspawns [nombreCofre]Lista los puntos de spawn fijos guardados, opcionalmente filtrando por cofre.
/dd event start <nombre>Inicia manualmente un drop event definido en /events.
/dd event stop [nombre]Detiene el drop event en curso.
/dd event listLista todos los drop events y su estado actual.

Alias: /donadrops. Todos los argumentos tienen autocompletado (nombres de cofre, categorías, 1-5, jugadores online).

Además de /dd spawn <nombre>, DonaDrops trae un spawneador automático por probabilidad (ver Spawneo automático): cada cofre respeta su propio spawn-chance y spawn-cooldown-seconds (o los valores globales de config.yml si no los define). Un cofre con spawn: true en su archivo nunca usa este buscador aleatorio: solo aparece en los puntos fijos creados con /dd createspawn.

Permisos

Nodo Default Descripción
donadrops.*opOtorga todos los permisos del plugin.
donadrops.createopPermite crear cofres, incluido el uso de /dd copy.
donadrops.spawnopPermite generar cofres, romperlos, usar /dd locate y /dd give.
donadrops.editoropPermite abrir el menú del editor gráfico (GUI).
donadrops.reloadopPermite recargar la configuración del plugin y refrescar los hologramas.
donadrops.topstruePermite ver el menú de clasificaciones y rankings.
donadrops.authortruePermite ver la información del autor usando /dd author.
donadrops.helptruePermite visualizar la lista de comandos con /dd help.
donadrops.notifyopRecibe notificaciones de inicio, errores en archivos YAML y alertas de nuevas versiones.
donadrops.opentruePermite a los jugadores interactuar y abrir los cofres generados.
donadrops.eventopPermite gestionar, iniciar, detener y listar drop events activos con /dd event.
